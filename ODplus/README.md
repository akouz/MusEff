# Овердрайв с ВЧ-клиппером

Клиппер с подмесом ВЧ сигнала описан [здесь](https://github.com/akouz/MusEff/tree/main/Clippers). Клиппирующие диоды D3 - Шоттки.  ВЧ генератор треугольного напряжения частотой  320 кГц собран на триггере Шмитта U3. 

Переключатель SW1 позволяет сравнить звучание с ВЧ сигналом и без него. Без подмеса ВЧ эффект звучит как довольно обычный, не очень жесткий овердрайв на Шоттки диодах. В нем слышится небольшой песок. Когда подмес ВЧ включен, песок полностью исчезает, звучание очищается и начинает напоминать звучание лампового овердрайва. 

![ODplus](https://raw.githubusercontent.com/akouz/MusEff/refs/heads/main/ODplus/ODplus_rev_2_1.png)

В звуковом примере каждый музыкальный фрагмент проигрывается два раза: первый раз в положении SW1 "HARD", второй раз - в положении "SOFT"
